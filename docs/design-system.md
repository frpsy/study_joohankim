# 스터디 홈 디자인 계약 (AI·사람 공통)

## 0. 기준과 범위
- 최종 기준은 assets/site.css의 :root 토큰과 assets/site.js의 공통 동작이다. 이 문서는 기존 스타일의 설계 의도를 설명한다.
- 현재 강의 페이지는 3단 요약 → 원본 댓글 타임라인, 학습 해설은 별도 미니강좌가 기준이다. 이전 마인드맵/독립 해설 의무 규칙은 현행 컴팩트 페이지에 적용하지 않는다.
- 페이지별 style 태그와 인라인 style 속성, 복제된 전용 복사 핸들러를 만들지 않는다. 새 화면을 추가할 때 같은 컴포넌트를 재사용한다.

## 2. 공통 구성과 반응형
- 모든 페이지: 공통 헤더·본문·푸터, 한 페이지 h1 하나, 44px 이상 터치 대상, 읽기 쉬운 왼쪽 정렬.
- 홈: lectures.json + scripts/build_library.py가 유일한 카드 데이터 원본이며 수동 카드 추가 금지.
- 강의: data/lecture_compact.json + scripts/build_compact_lectures.py; 미니강좌는 data/mini_courses.json, 5분 요약은 data/summaries.json에서 생성한다.
- 모바일 기준 분기점은 780px 이하, 매우 작은 화면 보정은 360px 이하를 유지한다. 좁은 화면은 한 열 본문, 가로 넘침 없이 자연스러운 줄바꿈, 최소 16px 입력 글꼴을 지킨다.
- 본문 코드블록은 pre-wrap / overflow-wrap을 유지하되 댓글 원문의 줄바꿈·시간정보·공백을 복사 과정에서 변경하지 않는다.
- sticky 메뉴·해시 앵커·접힌 영역 열기 동작을 유지한다. 기존 URL 앵커는 삭제하지 않는다.

## 3. 공통 상호작용 계약
- 댓글 복사는 data-copy-target이 가리키는 원문 textContent만 복사한다.
- 성공: 버튼 '복사 완료 ✓', 상태 '복사됨'. 2.2초 후 버튼 원래 이름과 상태 문구가 복원된다.
- 실패: 원문을 선택하고 '텍스트 선택됨' 및 직접 복사 안내를 제공한다.
- 상태는 role=status와 aria-live=polite로 알린다. 복사 버튼은 모바일에서도 폭을 독점하지 않는다.
- 검색·필터·목차·접기/펼치기·학습 기록은 assets/site.js 및 관련 공통 모듈에서 제공하며, 기능을 임의로 복제하지 않는다.

## 4. AI 변경 절차와 검증 증거
1. AGENTS.md → 편집규칙.md → 이 문서 → 저장소 스킬을 읽고 현행 레이아웃과 데이터 생성 경로를 확인한다.
2. 변경 범위와 의도하지 않은 영향(홈, 강의, 미니강좌, 개념집, 학습 이력, 링크, 모바일)을 먼저 명시한다.
3. 로컬 검사: python3 scripts/validate_design_system.py; python3 scripts/validate_site.py; python3 -m unittest discover -s tests; node --test tests/*.cjs.
4. PR의 네 가지 항목: 변경 범위 / 영향 기능 / 검증 증거 / 남은 위험. GitHub Actions의 정적·상호작용·반응형 스모크 결과를 확인한다.
5. 브라우저 자동화 검사는 실물 아이폰 Safari 검사의 대체물이 아니다. 검증하지 않은 환경은 미검증으로 기록하고, 배포 링크는 실제 공개 파일 확인 후 공유한다.

## 5. 변경 금지와 예외
- UI 작업 시 강의 텍스트·원자료·영상 시각·원문 댓글·진행 기록을 의도 없이 수정하지 않는다.
- 디자인 토큰 변경은 관련 페이지와 모바일/PC 화면에 대한 영향 분석을 포함해야 한다.
- 과거 레이아웃을 되살리는 변경은 명시적 사용자 요청이 없는 한 금지한다.
- 새 규칙은 기존 규칙과 중복·충돌하지 않는지 확인하고 AGENTS.md, 편집규칙.md, 스킬, 테스트 중 필요한 곳을 함께 갱신한다.
