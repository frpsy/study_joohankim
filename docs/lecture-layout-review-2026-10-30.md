# 강의 공통 레이아웃 적용

대상: 등록된 강의 5편. 기존 강의의 내용과 문체를 바꾸지 않고 구조·공통 표시를 정리했다.

## 구성

- 공통 헤더 → 제목/설명/정보/바로가기 3개 → 중요성과 학습 목표 → PC 왼쪽 목차/모바일 가로 목차 → 본문 → 홈·개념집 탐색 → 공통 푸터.
- 본문: 핵심 요약 → 주제별 해설 → 원본 화면(별도 자료가 있는 경우) → 학습 순서와 일상 적용 → 근거와 출처 → 댓글용 타임라인.
- 주제별 해설은 같은 topic 카드로 통일하고 첫 카드만 기본으로 연다. 전체 펼치기/접기와 댓글 복사는 공통 site.js에서 처리한다.
- 수용·용서에 기존 문답을 활용한 독립 복습 영역을 마련했다. 해설 안의 원래 문답과 감사 기록 연결도 보존했다.
- 모든 페이지에서 같은 복사 버튼과 접근성 상태 안내를 사용한다. 공통 자산 버전을 붙여 오래된 복사 코드가 캐시에 남는 문제를 피했다.
- 강의 하단은 홈·개념집 이동으로 통일하고 다른 강의 추천은 제거했다.

## 보존과 검증

- 변경 전후 기존 모든 ID, 이미지 src 95개 및 댓글 pre 원문 보존을 비교했다. 본문의 기존 p 문장도 누락이 없음을 비교했다.
- 생성 일치, validate_site.py, validate_study_pages.py, unittest 21개, 스킬 검사 통과.
- 실제 Chrome에서 PC CSS 폭 1309px/모바일 반응형 폭 354px로 5편 모두 검사했다. 목차 링크 31개를 두 폭에서 클릭하고 전체 펼치기·접기 및 실제 복사 원문 일치를 확인했다. 문서 가로 넘침 없음.
- 수용의 PC 복사 초기 결과가 일치하지 않아 성공 상태가 표시된 뒤 다시 읽어 일치를 확인했다. 모바일에서도 일치했다.
- 용서의 기존 #definitions 직접 링크가 해당 카드를 여는 것을 확인했다. 콘솔 오류 없음.
- 모바일 실기기 검사는 수행하지 않았다. 병합 후 공개 배포는 별도 확인한다.
