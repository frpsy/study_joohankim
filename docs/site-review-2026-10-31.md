# 스터디 홈 추가 검토 (2026-10-31)

범위: 홈, 용어와 개념, 강의 5편의 구조와 본문 점검. 기준은 main 4328467.

## 점검한 것
- 생성 일치 검사, 사이트 검사, 강의 검사, 단위 테스트 통과.
- 본문과 메타 설명에 남은 제작 사족 검색. 강의 내용에 대한 한계 설명만 남아 있어 그대로 둠.
- 중복 id, 대체 텍스트 없는 이미지, 깨진 페이지 안 앵커, 메타 설명, 언어 속성 점검.

## 고친 것
- 용서 강의 이미지 링크 17개에 `rel="noopener"`가 빠져 있어 추가했다.
- 같은 규칙을 지키는지 `tests/test_site_structure.py`의 `ExternalLinkRegression`으로 검사한다.

## 결정이 필요한 것
- 문체: 용서 강의는 한다체로 일관되고 나머지 강의는 합니다체다. 통일하려면 용서 강의 본문 전체를 바꿔야 한다. 현재는 그대로 둔다.
- 수용 강의의 접힌 해설 직접 링크는 배포 후 펼쳐지는지 실제 브라우저에서 확인해야 한다.

## 확인하지 않은 것
- 실제 휴대전화 기기 검사.
- 강의 내용의 재검수. 이번 작업은 구조와 HTML 점검이다.
