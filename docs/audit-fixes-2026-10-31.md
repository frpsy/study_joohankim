# 현상태 감사 후속 수정

- 기록 조회 실패 시 입력·저장 화면 대신 재조회 버튼만 표시합니다.
- 진행 상태·메모·이력을 Firestore writeBatch 하나로 저장합니다. 실패 시 현재 화면의 입력을 보존합니다.
- 홈 배지·강의 기록·학습 이력은 계정 상태 세대 번호를 대조하여 지연 응답을 무시하고 계정 전환 즉시 이전 화면을 비웁니다.
- 공개 홈·개념집·강의의 해요체 질문·명령형 안내와 UI 오류 안내를 합니다체로 교정했습니다. 인용과 댓글 원문은 보존했습니다.
- 편집규칙의 주간 일정을 월요일 09시 시작·10시 완료 목표로 맞췄습니다. Codex automation 설정의 ACTIVE·월요일 09시·프롬프트 10시 목표와 일치함을 확인했습니다. 기존 예약은 변경하지 않았습니다.
- Node 회귀 검사 6개는 조회 실패 후 재시도, 지연 조회와 계정 전환, 배치 저장 실패·재시도, 저장 후 로그아웃, 홈 배지와 이력의 이전 응답 무시를 모의 환경에서 검증합니다. 실제 사용자 데이터에 장애를 주입하거나 기존 메모를 변경하지 않았습니다.
- Python 검증 두 개·생성기 일치 두 개와 unittest 23개를 통과했습니다. 모든 강의 pre 원문의 변경 없음도 비교했습니다. 이번 수정은 강의 과학 내용의 원자료 재검수가 아닙니다.
