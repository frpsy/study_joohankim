# iPhone 홈 화면 앱 + PC 즐겨찾기 대응 계획

## 목표 및 배포 범위
- **iPhone:** Safari에서 홈 화면에 추가해 독립 창으로 실행하는 PWA(Progressive Web App, 설치형 웹 앱). App Store 등록·네이티브 iOS 프로젝트·개발자 계정 필요 없음.
- **PC:** Chrome/Edge/Safari/Firefox에서 **기존 URL을 즐겨찾기**로 열어 사용. 설치 안내·설치 버튼·PC 전용 앱 패키지는 제공하지 않음.
- 공통: 강의 원문·미니강좌·5분 요약·검색·댓글 타임라인 복사·원본 링크·버전 표시 유지. 로그인·개인 학습 기록 저장 금지.

## 구현 단계
1. **기존 기능 확인:** 정적 생성기와 7편의 URL/콘텐츠 ID를 보존하고 브라우저 회귀 테스트를 기준으로 확보한다.
2. **앱 셸:** `manifest.webmanifest`, 180px·512px 아이콘, iPhone 독립 실행 메타데이터, 홈 화면 안전 영역, 별도 `offline.html`을 추가한다.
3. **다크 모드:** 시스템 자동/라이트/다크의 3상태 선택, 한 기기에서만 저장되는 화면 선호 설정, 새 페이지·다시 열기·OS 테마 변경 연동. 개인 학습 데이터는 저장하지 않는다.
4. **오프라인:** 서비스 워커가 공통 셸과 현재 강의 7편의 강의 노트·미니강좌·5분 요약을 사전 저장한다. 원본 YouTube·외부 링크·다운로드되지 않은 큰 슬라이드 이미지는 오프라인을 보장하지 않는다.
5. **동작·보안 검증:** Chromium과 WebKit에서 360/390/768/1280px, PC 키보드·창 크기·다크 모드, 네트워크 차단 시 기본 읽기 동작, 장시간 사용 중 캐시 갱신, 수평 넘침 및 모바일 글자 크기를 검사한다.
6. **배포:** 생성기 재실행 → Python/Node/브라우저 자동 테스트 → PR → 병합 → GitHub Pages 실제 배포 확인.

## iPhone에서 사용하기
1. iPhone **Safari**에서 https://frpsy.github.io/study_joohankim/ 를 연다.
2. 공유 메뉴에서 **홈 화면에 추가**를 선택한다.
3. 홈 화면의 **내면의 서재** 아이콘을 열면 Safari의 주소 표시줄 없이 앱처럼 이용할 수 있다.
4. 헤더의 **화면 · 시스템** 버튼을 눌러 시스템 → 라이트 → 다크 순서로 바꾼다. 기본값은 iOS 화면 설정을 자동으로 따른다.
5. 첫 방문 시 인터넷 연결 상태에서 사이트를 연 다음 강의 자료 저장이 완료되면 오프라인에서 읽을 수 있다. 일부 외부 링크와 원본 영상 재생은 네트워크가 필요하다.

## PC에서 사용하기
- 사이트를 기존 브라우저에서 열고 **즐겨찾기**에 추가한다. 별도 설치를 요구하지 않는다.
- 헤더에서 테마 선택이 가능하고 PC의 시스템 다크 모드도 자동 감지한다.
- 선택한 테마는 해당 브라우저의 `localStorage`에만 저장하며 개인 계정, 강의 진도, 학습 이력은 저장하지 않는다.

## 완료·한계
- 앱으로 **보이는 것**과 **네이티브 iOS 앱인 것**은 다르다. iOS 기기에서 직접 설치한 실기기 검수는 자동 브라우저(WebKit) 검수와 별개다.
- PWA는 WebKit/OS 정책에 따라 저장 공간과 백그라운드 오프라인 캐시가 제거될 수 있어 모든 상황의 영구 오프라인 보관을 보장하지 않는다.
- 사용자가 요청한 PC 사용 흐름은 웹 즐겨찾기이며 PC 앱 설치 UX를 따로 만들지 않는다.
