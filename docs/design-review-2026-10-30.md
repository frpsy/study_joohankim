# 학습 웹 디자인 정비 기록 · 2026-10-30

## 확인한 문제

1. 홈·최근 강의·이전 강의·개념집이 각자 인라인 CSS를 사용해 본문 폭, 제목, 카드, 메뉴가 달랐다.
2. 강의 상단에 홈 복귀·다른 강의 배너·브랜드 바가 중복됐다. 개념집에는 공통 메뉴가 없었다.
3. 최근 강의는 학습 해설보다 화면 24개가 먼저 나와 읽는 흐름이 길게 끊겼다.
4. 홈은 소개 영역과 세로 목록이 길었고, 개념집 38개는 검색 없이 나열됐다.
5. 삭제한 기록 입력 기능을 권하는 홈 문장이 남아 있었다.
6. 이전 작업에서 삭제한 DOM을 구형 생성 스크립트가 참조해 복사 초기화가 중단된 사례가 있었다. 구조와 동작을 함께 검증해야 한다.

## 수정 순서와 구현

- 공통 site.css/site.js와 상단 메뉴·하단 복귀 링크·현재 위치를 적용했다.
- 홈을 최근 강의 진입점, 주제 검색, 최신순 2열 카드로 바꾸었다. 목록은 lectures.json에서 build_library.py로 생성한다.
- 강의는 핵심 요약 → 학습 해설 → 관련 화면 순서를 우선한다. 기존 각 절의 ID와 이미지·본문은 유지했다.
- 개념집에 설명까지 검색하는 입력과 빠른 필터를 추가했다. 정리된 강의가 있는 개념은 내부 해설로 연결한다.
- 예전 해설 내부 주소를 열면 상위 접힌 영역도 자동으로 펼친다. 관련 개념은 강의 주제로 검색한 상태로 연결한다.
- 모바일 상단 메뉴 줄바꿈을 확인해 이름을 한 줄로 줄이고 세부 부제를 숨겼다.

## 검수 기록

- 기존 이미지 24+53개와 해설 단위 5+12개, 기존 ID 보존 검사.
- 홈 검색·검색 결과 없음·전체 복귀, 최근 강의 진입과 개념 검색 확인.
- 해설 전체 접기, 해설 내부 주소 진입 시 상위 절 자동 펼침 확인.
- 삭제된 개인 기록 UI를 다시 만들지 않는다.
- 자동 구조·링크 검사와 회귀 테스트, 실제 PC·모바일 검수를 나누어 수행한다. 최종 공개 배포 검수는 완료 보고의 근거로 별도 기록한다.

## 재발 방지

규칙은 편집규칙의 공통 디자인 절, 자동 검사는 validate_site.py와 test_site_structure.py에 남긴다. 이후 결함은 이 문서를 덮어쓰지 말고 docs/design-review-YYYY-MM-DD.md에 문제·원인·수정·확인 결과를 추가한다.

검수 결과: 구조·로컬 링크 검사 통과, 회귀 검사14개 통과. 로컬 브라우저에서 홈 검색·빈 결과·전체 복귀·깊은 링크 자동 펼침·해설 접기·댓글 실제 클립보드 일치를 확인했다. 모바일 실제 viewport355에서 홈·강의2개·개념집 가로 넘침이 없었고, 헤더 줄바꿈은 수정 후 재확인했다.
