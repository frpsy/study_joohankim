# 내면의 서재 — 다중 출처·자료 유형 콘텐츠 모델

## 목적
내면의 서재는 특정 강연자 전용 페이지가 아니라 여러 강연·책·연구·글을 연결하는 개인 학습 공간이다. 현재 강의 6편은 기존 소유자의 학습 자산으로 유지한다. 향후 새 항목을 **실제 원문을 확보한 뒤** 별도 유형으로 추가한다.

## 자료 등록 계약
### 영상 강의 — `lectures.json`
- 필수: `id`(11자 YouTube ID), `kind: "lecture"`, `creator`(실제 화자), `title`, `duration`, `description`, `tags`.
- 날짜는 확인된 공개일만 `date`로 기록하고, `filter_tag`는 필요할 때만 사용한다.
- 기존 `lectures/<id>.html`, `mini-courses/<id>.html`, `summaries/<id>.html`, `studyUsers/<uid>/progress/<id>`의 연결을 **바꾸지 않는다**.
- 원본 자막, 타임코드, 동영상 링크, 논문 근거, 개인 학습 기록을 보존한다. 강연자별 해설 규칙을 혼동하지 않는다.

### 책·연구·글·개인 노트 — `materials.json`
현재 값은 `[]`로 시작한다. 새로운 자료가 있을 때만 등록한다.

| 필드 | 설명 |
|---|---|
| `id` | 전체 자료를 통틀어 중복되지 않는 안정적인 식별자 |
| `kind` | `book` · `paper` · `article` · `note` |
| `creator` | 책 저자, 연구자, 글쓴이 등 실제 출처 |
| `title` | 자료 제목 |
| `description` | 학습 자료의 핵심 설명 |
| `tags` | 주제 태그 배열 |
| `url` | 실제 작성 완료된 **사이트 내부 상대경로**. 예: `books/sample.html` |

등록하기 전에 실제 내부 HTML 문서를 생성하고 출처 및 링크를 확인한다. URL은 절대 URL·상위 디렉터리 이탈을 허용하지 않는다. 기존 강의처럼 모든 자료에 동영상 타임라인이나 3단 요약을 강제하지 않는다. 자료 유형별로 적절한 독서 노트, 논문 분석, 미니강좌 등의 서식을 선택한다.

## 사용자 경험과 운영 규칙
- 사이트 이름과 소개는 자료 유형·강연자에 중립적이다. 상단 **자료 모음 / 용어와 개념 / 학습 이력**의 공통 구조를 유지한다.
- 자료 카드에는 실제 출처를 표시하며 검색은 제목·설명·강연자/저자·주제 태그를 모두 대상으로 한다.
- `lectures.json`과 `materials.json`은 공통 목록에서 합쳐 표시하지만 원본 파일과 생성기/검증 규칙은 분리한다. 카드와 학습 기록 저장을 분리해 새로운 `book` ID가 동영상 저장 경로로 취급되지 않게 한다.
- 강의별 학습/복습 기록은 기존 동영상 ID를 그대로 유지한다. 향후 책·연구 진행률이 필요하면 **자료 유형을 구분하는 새 저장 경로와 데이터 마이그레이션 계획**을 별도 검토한다.
- 신규 자료/브랜드 변경 후 `scripts/build_library.py`, `scripts/validate_site.py`, 생성기 --check 및 Python/Node/Chromium 검사를 통과시킨다.
- 새 콘텐츠는 사실상 작성 완료한 내부 페이지가 있어야만 등록하며 존재하지 않는 책·논문을 예시 카드로 게시하지 않는다.

## 강연자별 편집 기준
김주환 교수의 내면소통 강의에 적용하던 자막/용어 스타일은 **해당 강의의 편집 규칙**이다. 허버먼의 강의에는 해당 강의의 영어 원본과 학술 자료, 다른 저자의 책에는 저작권과 인용·판본 정보가 기준이다. 서로 다른 원문의 주장을 한 강연자의 주장으로 합치지 않는다.
