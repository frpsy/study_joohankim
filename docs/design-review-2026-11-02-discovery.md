# 홈 탐색 개선 · 2026-11-02

## 변경 범위
홈 생성기·공통 검색 JS·공통 CSS·정적 자원 버전. 학습 흐름을 짧은 링크 세 개로 표시하고 검색 초기화를 제공한다. 편집 순서 첫 항목의 ‘최근 정리’ 오표기를 ‘대표 강의’로 바꾼다.

## 영향 기능
홈 검색의 URL q 보존, 새로고침·뒤로 가기 복원, 칩 선택·결과 수·초기화. 기존 개념집 검색은 주소 쓰기를 활성화하지 않는다. 인증·학습 데이터 저장·타임라인 원문은 수정하지 않는다. 공통 생성 파일은 같은 자산 버전으로 재생성한다.

## 검증 방법
디자인/사이트 검사, 전체 Python/Node 회귀 검사, 생성기 일치 검사. PR CI의 Chromium 모바일·PC·검색 복귀 검사를 확인한다. 실제 iPhone Safari 및 실제 Google 계정 로그인은 미검증이다.

## 회귀 위험
공통 JS 검색 이벤트가 개념집에 영향을 줄 수 있어 기존 검색 검사를 유지한다. Service Worker/표시 버전/자산 URL을 함께 갱신하여 오래된 자원 조합을 줄인다.
