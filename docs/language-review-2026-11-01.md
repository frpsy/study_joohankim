# 스터디 홈 3단계 한국어 문장 교정

작성일: 2026-11-01 · 저장소: frpsy/study_joohankim

## 목적과 기준
화면 안내부터 강의 원고까지 ‘~한다/~이다’ 어미를 기계적으로 반복하던 편집 기준을 폐지한다. 짧은 UI 상태에는 구체적인 명사구, 오류에는 다음 행동이 드러나는 문장, 강의 본문에는 정확하고 읽기 자연스러운 해설을 사용한다. 단순히 모든 서술어를 명사형으로 바꾸지는 않는다.

## 1단계: 화면 전반
- 홈의 강의 설명과 검색/로그인 상태, 용어집 44개 카드, 학습 이력의 소개·상태를 검토했다.
- assets/account.js와 assets/progress.js의 로그인·기록 저장 상태를 고쳤다. ‘저장했다.’ → ‘저장 완료’, ‘저장하지 못했다.’ → 다음 행동을 안내하는 구체적인 오류 메시지.
- 용어 정의의 의미·조건·주의를 보존하되, 필요한 문장은 그대로 유지했다.

## 2단계: 강의 6편
- data/mini_courses.json의 여섯 강의 모두 3단 요약 도입과 핵심 항목, 미니강좌 소제목·설명·질문 답을 교정했다.
- data/summaries.json의 여섯 강의 모두 5분 요약의 도입, 소제목, 적용 문장과 일부 해설을 교정했다.
- lectures/, mini-courses/, summaries/의 HTML을 데이터 원고에 맞춰 동기화했다. 기존 자료·영상 링크·원본 댓글 타임라인·기존 앵커는 유지했다.
- 과학적 주장, 논문의 연구 범위와 근거 수준, 경전 인용의 출처는 문체를 이유로 바꾸지 않았다.

## 3단계: 재발 방지와 검증
- AGENTS.md와 저장소 전용 스킬에 세 단계 검수 흐름을 추가했다.
- 자동 테스트에서 반복된 옛 문구를 탐지하고, 홈·강의·요약·미니강좌 데이터 생성 일치와 UI 상태 변경을 검사한다.
- 브라우저 검사 대상에 용어집·학습 이력·5분 요약을 추가했다. 360px·390px·1280px 화면의 레이아웃 검사를 자동화했다.
- 완료 기준: GitHub Actions 품질/브라우저 검사 성공 + PR 병합 + GitHub Pages 배포 성공. 실물 아이폰 Safari에서 직접 보지 않은 부분은 별도 검증으로 남긴다.

## 수정 범위와 제외 사항
이 작업은 **문장 편집**이 목적이다. 자막을 새로 추출하거나 원본 영상의 모든 학술 주장을 재검증하는 작업은 포함하지 않는다. 학습 이력 데이터와 로그인 기능의 저장 형식은 변경하지 않았다.
