# 용서 강의 작업 재발 방지 기록

## 원인과 조치

- 유튜브 영상 추출 실패를 전체 중단으로 취급했다. 기존 Windows .video-tools의 yt-dlp, yt_dlp_ejs와 Node 실행 환경을 함께 사용하여 복구했다.
- 도구 위치를 확인하지 않은 채 영상 처리 도구가 없다고 판단했다. 다음에는 기존 작업 폴더와 실행 환경을 먼저 확인한다.
- 자막 변환은 빈 줄로 VTT를 나누면서 첫 발화를 누락시켰다. 타임코드 경계로 구분하고 첫/마지막 발화를 원본과 확인한다. 롤링 자막의 반복은 독서용 변환과 원본 보존을 구분한다.
- 화면 표본 추출과 전체 검토를 혼동하지 않는다. 확보 화면 수·탐색 간격·후보 재검토 범위와 제한을 별도로 기록한다.
- 원고를 만든 뒤 독립 검수자가 실제 원고와 원자료를 대조하고 오류를 수정한다. 원고 없는 검수는 최종 검수가 아니다.
- 상태는 원자료 확보, 범위 검토, 원고, 독립 검수, 구조 검사, 게시, 공개 확인으로 나눈다. 실패 단계가 있어도 독립적으로 진행 가능한 작업을 계속한다.

## 운영

이 작업은 Windows의 lecture_forgiveness 자료와 최신 forgiveness-site 저장소를 사용한다. WSL 자료와 이전 unused 아카이브는 근거로 사용하지 않는다. 공개 댓글은 게시하지 않는다.
