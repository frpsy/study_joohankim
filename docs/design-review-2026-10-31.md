# 마인드맵 정렬 재검수

기존 배치는 중심 상자와 좌우 가지 연결점의 중점이 달라 왼쪽으로 치우쳐 보였다. 고정 제목·항목 높이로 불필요한 빈 줄도 생겼다.

연결점을 각 가지 영역 중앙으로 옮기고 영역 안의 글자는 왼쪽으로 정렬했다. 제목 행은 subgrid로 실제 높이를 공유하며 항목은 자연스러운 줄 높이를 사용한다. 1000px 이하에서는 세로 트리로 전환한다.

Chrome PC 1309px에서 다섯 강의의 중심 오차 0.002px 미만, 하위 목록 시작 높이 일치, 가로 넘침 없음. 모바일 354px에서 명상 강의 세로 트리와 넘침 없음을 확인했다. 생성기 두 개의 --check, 사이트 검증 두 개, unittest 22개 통과. 이번 검수는 디자인 변경 범위이며 강의 원자료 재검수를 의미하지 않는다.
