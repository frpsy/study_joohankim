# 마인드맵 정렬 재검수

기존 배치는 중심 상자와 좌우 가지 연결점의 중점이 달라 왼쪽으로 치우쳐 보였다. 고정 제목·항목 높이로 불필요한 빈 줄도 생겼다.

연결점을 각 가지 영역 중앙으로 옮기고 영역 안의 글자는 왼쪽으로 정렬했다. 제목 행은 subgrid로 실제 높이를 공유하며 항목은 자연스러운 줄 높이를 사용한다. 1000px 이하에서는 세로 트리로 전환한다.

Chrome PC 1309px에서 다섯 강의의 중심 오차 0.002px 미만, 하위 목록 시작 높이 일치, 가로 넘침 없음. 모바일 354px에서 명상 강의 세로 트리와 넘침 없음을 확인했다. 생성기 두 개의 --check, 사이트 검증 두 개, unittest 22개 통과. 이번 검수는 디자인 변경 범위이며 강의 원자료 재검수를 의미하지 않는다.

## 미니멀 마인드맵과 문체 후속 반영

같은 높이의 가지 박스가 짧은 목록의 빈 공간을 강조했다. 박스 외곽을 제거하고 위쪽 연결선만 유지했다. 중심 정렬과 제목 행 공유를 유지하되 목록은 내용 높이로 표시한다. 중심 노드도 밑줄만 사용한다.

인용 외 완결 문장은 합니다체로 쓰는 공통 규칙을 편집규칙과 전용 스킬에 추가했다. 공개 HTML의 한다·이다·된다·있다·없다·했다 종결 후보를 검색한 결과 문장부호로 끝나는 해당 후보는 없었다. 제목·원본 인용은 문맥별 보존 기준을 명시했다.

## 학습 기록 최소화

학습 기록의 외곽 카드·큰 제목·계정명·상시 입력란을 없애고 기본 접힘 한 줄로 바꿨습니다. 저장된 학습·복습 완료와 메모 유무를 요약하며 오류 때는 자동으로 펼칩니다. 메모는 두 줄로 시작하며 저장·계정 전환 보호는 유지합니다.

## 모바일 메모 포커스 확대

모바일 textarea의 16px 규칙 뒤에 font:inherit가 선언되어 축소 카드의 14px를 상속했습니다. textarea 최종 선언에 16px를 명시하여 단축 속성의 덮어쓰기를 제거했습니다. 사용자 확대 제한은 추가하지 않습니다.
