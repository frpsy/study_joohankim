# 강의 마인드맵

사용자 요청에 따라 강의 5편 모두 핵심 요약과 상세 해설 사이에 마인드맵을 추가했다. 각 강의의 기존 핵심 요약·해설에서 중심 개념과 네 가지 가지를 구성했다. 세부 항목 44개는 해당 설명 앵커로 연결한다. 새로운 인과 주장이나 시각 자료를 만들어 넣지 않았다.

디자인은 기존 종이색과 녹색 글자를 유지하고 가는 연결선·여백으로만 계층을 표현했다. PC에서는 가로 가지 구조, 모바일에서는 세로 트리로 표시한다. 별도 라이브러리나 이미지 생성 없이 의미 있는 HTML 목록과 공통 CSS로 구성했다.

개념 데이터는 data/lecture_mindmaps.json, 생성기는 scripts/build_mindmaps.py다. --check 검사와 validate_site.py에 데이터·페이지 일치 검사를 연결하고, 공통 레이아웃과 규칙·스킬에 마인드맵 단계를 반영했다.

검증: 두 생성기 --check, 사이트·강의 검사, unittest 22개, 스킬 검사 통과. 실제 Chrome에서 PC 1309px/모바일 반응형 354px의 5편을 확인했고 문서 가로 넘침 없음. 최종 44개 링크를 클릭해 hash와 접힌 해설 자동 펼침을 확인했다. 초기 검사의 즉시 상태 읽기에서 실패처럼 보인 링크는 화면 상태를 기다린 뒤 다시 검사해 모두 정상임을 확인했다. 휴대전화 실기기 검사는 수행하지 않았다. 병합 후 공개 배포를 별도로 확인한다.
