# 읽기 화면 전체 정돈

- 모바일 헤더가 약 93px로 늘어나는데 목차는 60px에 고정되어 가려졌다. ResizeObserver와 resize 이벤트로 실제 헤더·목차 높이를 계산하고 CSS 위치·앵커 여백에 반영한다.
- 주제 컨테이너는 유지하며 내부 연녹색 박스·질문 배경·원본 화면의 중첩 외곽선을 제거했다. 제목·본문·보조 동작의 굵기와 여백을 구분했다.
- 홈·개념집 검색의 외곽 박스를 제거하고 모바일 칩을 한 줄 가로 탐색으로 바꿨다. 선택 상태를 aria-pressed로 표시한다. 모바일 홈 첫 강의 카드 시작점은 CSS 폭 354px에서 약 617px다.
- 다섯 강의 각각 CSS 폭 354·698·1163px에서 가로 넘침·헤더 목차 겹침이 없었다. 명상 강의 해설 전체 펼치기·접기와 댓글 원문 복사 일치를 확인했다. 원자료·본문 내용은 변경하지 않았다.
- 홈·요약·마인드맵 생성 일치, 사이트·강의 검증, Python 25개와 Node 6개 검사를 통과했다. 실제 휴대전화 검사가 아닌 Chrome 반응형 검사다.
