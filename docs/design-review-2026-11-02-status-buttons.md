# 학습 상태 버튼 간소화

## 변경 범위 / 영향 기능
공통 progress.js를 접기 토글·체크박스·별도 저장 폼에서 즉시 저장하는 일반 버튼 두 개로 변경한다. 완료하면 체크 표시, 재클릭하면 취소한다. 로그인 전에는 짧은 연결 링크를 제공한다. 홈·요약·미니강좌·개념집의 콘텐츠는 유지하며 공통 자산 버전만 동기화한다.

## 데이터 및 회귀 위험
선택 필드만 merge하여 다른 상태를 덮어쓰지 않으며 완료 상태와 이력을 같은 batch로 저장한다. 기존 notes 문서는 유지한다. 조회 실패 시 변경 버튼을 표시하지 않는다. 쓰기 실패·중복 클릭·계정 전환·로그아웃 후 늦은 응답을 검사한다.

## 검증 증거
디자인/전체 사이트 검사와 생성기 일치, Python 38개·Node 10개 통과. CI에는 로그인된 SDK fixture로 360px/1280px 버튼 노출·터치 영역·직접 저장·취소 검사를 추가한다. 실제 계정과 iPhone Safari는 미검증이다.
