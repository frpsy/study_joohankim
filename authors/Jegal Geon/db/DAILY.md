# 일일 요약 절차 (제갈건 · 장자 길라잡이)

매일 1편씩 `lectures.json`의 `pending` 중 회차가 가장 낮은 것을 요약하고 노션에 정리한다.

1. `main`을 최신으로 받는다. `db/lectures.json`에서 `status == "pending"`인 가장 낮은 `lecture_no`를 고른다. 없으면 완료를 보고하고 루틴을 비활성화한다.
2. 자막 파일 전체를 읽는다(`tr '\n' ' '`로 한 줄로 만든 뒤 `Read`의 `allow_large`로 읽는다). 일부만 읽고 요약하지 않는다.
3. 요약 규칙
   - 자막에 나온 내용만 쓴다. 추측하지 않는다. 간결하게, 사족 없이 쓴다.
   - 강연자의 개인 견해는 '강연자의 견해'로 표시한다.
   - 자동 인식 오류로 판단한 부분은 `notes`에 적는다. 확신이 없으면 고치지 않고 그대로 둔다.
   - JSON 필드: `summary`(3~5개 항목), `keywords`, `notes`, `status: "summarized"`.
4. 노션 (부모: `notion_parent_url`, '장자 길라잡이 — 제갈건')
   - 먼저 `장자 길라잡이 N강`으로 검색하고 부모 페이지의 하위 페이지를 확인한다.
   - 이미 페이지가 있으면 기존 내용은 지우지 않고, 맨 아래에 `## 자막 기반 요약 (YYYY-MM-DD)` 섹션을 추가해 병합한다.
   - 없으면 부모 아래에 새 페이지를 만든다. 제목은 `장자 길라잡이 N강 — 제목`(N은 0 없이), 아이콘은 🦋. 본문은 `## 강의 정보` / `## 핵심 요약` / `## 출처·비고` 순서이며 `lecture_no` 2~6의 기존 페이지를 따른다.
   - 만든 페이지 주소를 JSON의 `notion_url`에 기록한다.
5. `python3 -I scripts/build_author_index.py "authors/Jegal Geon"`로 `INDEX.md`를 다시 만든다.
6. 커밋하고 `main`에 병합해 `main`과 `claude/hopeful-clarke-fcx6wd`를 모두 푸시한다. 커밋 메시지 끝에는 세션 안내가 요구하는 Co-Authored-By 줄을 붙인다.
7. 사용자에게 한국어 존대어로 한두 줄만 보고한다(회차, 제목, 노션 링크, 남은 편수).
